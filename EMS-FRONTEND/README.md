# Employee Management System - Frontend

Employee Management System frontend built using React.js.

## Features

- Add Employee
- Update Employee
- Delete Employee
- View Employee List
- REST API Integration
- Responsive UI

## Tech Stack

- React.js
- React Router DOM
- Axios
- Bootstrap

## Project Structure

```bash
src/
 ├── components/
 ├── services/
 ├── App.js
 └── main.jsx
```

## Installation

Clone the repository:

```bash
git clone https://github.com/Utshav451/employee-management-system.git
```

Navigate to frontend folder:

```bash
cd ems-frontend
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```

The application will start at:

```bash
http://localhost:5173
```

## API Connection

Make sure the Spring Boot backend server is running on:

```bash
http://localhost:8080
```
