# EMS Project

This is a full-stack Employee Management System.

## Structure

- ems-frontend → React frontend
- ems-backend → Spring Boot backend

## How to run

### Frontend
```bash
cd EMS-FRONTEND
npm install
npm run dev
```

### Backend
Using Maven:
```bash
cd EMS-BACKEND
mvn spring-boot:run
```
Or run directly from your IDE.
